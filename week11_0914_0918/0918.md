# CI/CD

## 2. Argo CD

### 7) Argo CD와 GitHub 연동하여 Kubernetes 클러스터에 배포하기

GitHub 저장소에 Kubernetes 매니페스트를 저장하고, Argo CD가 해당 저장소를 감시하여 클러스터에 배포하도록 구성한다.

#### 1. Kubernetes 매니페스트 작성

`manifest` 디렉터리에 네임스페이스, Deployment, Service 매니페스트를 생성한다.

**네임스페이스 생성 — `manifest/ns.yaml`**

```yaml
apiVersion: v1
kind: Namespace
metadata:
  name: bgd
```

**Deployment 생성 — `manifest/deployment.yaml`**

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  labels:
    app: bgd
  name: bgd
  namespace: bgd
spec:
  replicas: 1
  selector:
    matchLabels:
      app: bgd
  strategy: {}
  template:
    metadata:
      labels:
        app: bgd
    spec:
      containers:
        - image: ggnagpae1/bgd:1.0.0
          name: bgd
          env:
            - name: COLOR
              value: "blue"
          resources: {}
```

**Service 생성 — `manifest/svc.yaml`**

```yaml
apiVersion: v1
kind: Service
metadata:
  labels:
    app: bgd
  name: bgd
  namespace: bgd
spec:
  type: NodePort
  selector:
    app: bgd
  ports:
    - port: 8080
      protocol: TCP
      targetPort: 8080
      nodePort: 31080
```

작성한 `manifest` 디렉터리를 GitHub 저장소에 커밋하고 push한다.

#### 2. Argo CD Application 생성

Argo CD가 설치된 운영체제에서 `bgd-app.yaml` 파일을 작성한다.

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: bgd-app
  namespace: argocd
spec:
  destination:
    namespace: bgd
    server: https://kubernetes.default.svc
  project: default
  source:
    repoURL: https://github.com/itstudy001/bgd.git
    path: manifest
    targetRevision: main
```

Application 매니페스트를 배포한다.

```bash
kubectl apply -f bgd-app.yaml
```

#### 3. 애플리케이션 동기화

Argo CD는 기본적으로 Application을 생성한 뒤 Git 저장소의 상태와 클러스터의 상태가 다름을 알려주지만, 자동으로 동기화하지는 않는다. 최초 한 번은 수동 동기화를 수행한다.

```bash
argocd app sync bgd-app
```
